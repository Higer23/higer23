# Contributing to this profile repository

Thanks for helping improve this GitHub profile repository.

## Before opening a pull request

- Keep changes relevant to the profile, its documentation, or its displayed project information.
- Check links, image URLs, Markdown formatting, and alt text before submitting.
- Prefer small, focused changes that are easy to review.
- Describe what changed and how you checked it in the pull request.
- Do not add secrets, access tokens, private information, or credentials.

## Collaboration and co-authorship

If two people genuinely worked together on the same commit, the commit message may include a `Co-authored-by` trailer for the other contributor. Only include a person who actually contributed to that commit, and use an email address associated with their GitHub account. A pull request should contain a real, reviewable change; do not add attribution solely to try to obtain a profile achievement.

## Review checklist

- [ ] The change has a clear purpose.
- [ ] Markdown and links were checked.
- [ ] Images have useful alternative text.
- [ ] No secrets or personal data were introduced.
- [ ] The pull request explains the change and any checks performed.

## Mobile contribution checklist

When contributing from a phone or tablet:

- Check that the changed files render correctly on narrow screens.
- Preview Markdown changes before submitting the pull request.
- Use descriptive commit messages that explain the purpose of the change.
- Review the final diff and confirm that no unrelated files were modified.
- Test links and image references after the change is published.
- Report any checks that could not be run from the mobile device.
